# M7 证据：net80211 + urtwn + wpa 端到端（TLSF 堆后首次全阶梯闭环）

日期：2026-09-22 ｜ 镜像：ThreadX 主线 `make all`（freewebcamera `3b06225`，net_80211 `1b551a0`）
部署 sha256 对拍一致；全程 KI-001 冷启动、board_acquire 纪律。

## 验收阶梯（2026-09-22 boot-152237 全程串口实录）

1. **attach 零 fault**：`urtwn0: Realtek RTL8188EU, addr 3` → `urtwn0: MAC/BB RTL8188EU, RF 6052 1T1R, address 20:f4:1b:52:8f:01` → `1 rx pipe, 2 tx pipes` → `usbh: bus1 hub3 port1 claimed 0bda:8179 (high)`。窗口内无 `fatal[`、无 `heap: BAD FREE`、无 TLSF CHECK FAILED。shell 全程存活。
2. **scan**：`wlan scan 6` 返回 20+ 真实 BSSID（ch 2412–2462，open/enc 均有），rx 路径与 cherryusb API 映射验证。
3. **wpa**：`wpa start` → `wpa: supplicant running`；`wpa connect QiQiJia paopaojie520` → `Trying to associate with 14:a3:2f:18:07:2c (freq=2412)` → `Associated` → `WPA: Key negotiation completed [PTK=CCMP GTK=CCMP]` → `CTRL-EVENT-CONNECTED`。（偶发一次 auth timeout 后自动重试成功——supplicant 自身重试机制正常。）
4. **DHCP**：ASSOC 自动 `dhcp_start`；`wlan net` → `wl: ip=192.168.0.249 gw=192.168.0.1 mask=255.255.255.0`，`link=up dhcp_bound=yes`。
5. **ping**：`net down 0`（排除 eth0 同网段路由截胡）→ `ping 192.168.0.1 4` → `32 bytes from 192.168.0.1:icmp_seq=1 time=3 ms`（vendored lwIP apps/ping raw 模式，wl netif 路径）。

## 开放 bug 定案（attach 窗口野写）

- **证据**：fault 记录器（tx_glue.c）抓到 fault[0]：`ESR=02000000 ELR=0 LR=0`，两名死者为 slot4(task_net_start)/slot7(task_usb_start) 原始线程（state=LIVE、阻塞中），其栈顶保存上下文 12 字全 0——保存上下文被整块清零，属堆别名/误回收类损坏；自写 first-fit 堆为根因载体。
- **修复**：`third-party/tlsf`（mattconte TLSF v3.1，BSD-2）替换自写堆，`heap.c` 只留 API 适配 + SMP 锁 + 操作环形记录（带调用者返回地址）+ assert 接故障打印。替换后连续多轮冷启动零复现。
- 辅助修复：usbdi xfer 保留 DMA 块 raw 指针（sysmemalign 内部指针 free 陷阱，net_80211 `1e11be2`）；cmsis slot 原子预留 + TX_DONT_START；wlan-work 优先级 0→5；控制台单锁（board_console_write）。
